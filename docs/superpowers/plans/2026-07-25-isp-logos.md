# ISP Logos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render an admin-set logo image next to each ISP's name in the Overview page's bento grid (`web/src/components/isp-bento-grid.tsx`).

**Architecture:** A new `ISPLogo` DB table keyed by ISP name (not a `DNSServer` field, since one ISP name spans multiple server rows) holds an admin-supplied logo URL. A small CRUD API + admin UI section (mirroring the existing Compliant IPs manager) lets an admin-or-dept-admin set/remove it. The bento grid fetches the full ISP→logo map once and renders each logo inside a fixed-size neutral chip that normalizes mismatched source aspect ratios.

**Tech Stack:** Go (chi router, GORM/Postgres), React + TypeScript, existing `@/components/ui/select` and `animate-ui/dialog` primitives.

## Global Constraints

- Logos are admin-supplied URLs only — no file upload, no server-side fetch/caching (per `docs/superpowers/specs/2026-07-25-isp-logos-design.md`, "Decisions").
- `ISPLogo` is keyed by ISP name (string primary key), not FK'd to `DNSServer`.
- ISP Logos admin UI section is scoped **admin-or-dept-admin** (`requireAnyAdmin`), not admin-only — matches DNS server mutation scope.
- `ListISPLogos` (`GET /api/isp-logos`) is readable by **any authenticated role** — the bento grid needs it for every user, not just admins.
- Follow existing `writeInternalError`/`writeError` conventions for all new handlers — never return raw `err.Error()`.
- Store methods for one aggregate (`ISPLogo`) go on their own sub-interface (`ISPLogoStore`), per `CLAUDE.md`'s "When adding a function that only touches one aggregate, take that sub-interface as its parameter" convention.

func (s *postgresStore) UpsertISPLogo(ctx context.Context, isp, logoURL string) (ISPLogo, error) {
	logo := ISPLogo{ISP: isp, LogoURL: logoURL}
	err := s.db.WithContext(ctx).Clauses(clause.OnConflict{
		Columns:   []clause.Column{{Name: "isp"}},
		DoUpdates: clause.AssignmentColumns([]string{"logo_url"}),
	}).Create(&logo).Error
	return logo, err
}

func (s *postgresStore) DeleteISPLogo(ctx context.Context, isp string) error {
	return s.db.WithContext(ctx).Delete(&ISPLogo{}, "isp = ?", isp).Error
}

func (h *Handlers) UpsertISPLogo(w http.ResponseWriter, r *http.Request) {
	var body struct {
		ISP     string `json:"isp"`
		LogoURL string `json:"logo_url"`
	}
	if err := json.NewDecoder(r.Body).Decode(&body); err != nil || body.ISP == "" || body.LogoURL == "" {
		writeError(w, http.StatusBadRequest, "isp and logo_url are required")
		return

	logo, err := h.store.UpsertISPLogo(r.Context(), body.ISP, body.LogoURL)
	if err != nil {
		writeInternalError(w, err)
		return
	}
	writeJSON(w, http.StatusCreated, logo)
}

func (h *Handlers) DeleteISPLogo(w http.ResponseWriter, r *http.Request) {
	isp, err := url.PathUnescape(chi.URLParam(r, "*"))

		return
	}
	if err := h.store.DeleteISPLogo(r.Context(), isp); err != nil {
		writeInternalError(w, err)
		return
	}
	w.WriteHeader(http.StatusNoContent)
}
